# Project-Based Practice: посткалибровка вероятностей эмоций

Небольшой учебный проект на датасете RAVDESS. Скрипты читают речевой
ZIP-архив, создают таблицу с эмоциями и извлекают MFCC-признаки.

## Быстрый запуск

```bash
git clone https://github.com/brattsew/project-based-practice.git
cd project-based-practice
uv sync
```

После установки положите `Audio_Speech_Actors_01-24.zip` в `data/raw/` и
выполните:

```bash
uv run ravdess-convert
uv run ravdess-features
uv run ravdess-classify
```

## Важно о скачанном архиве

Для проекта используется речевой архив `Audio_Speech_Actors_01-24.zip`.
Положите его в `data/raw/`. Архив распаковывать не нужно: конвертер умеет
читать WAV-файлы прямо из ZIP. Скачать архив можно с официальной страницы RAVDESS:
<https://zenodo.org/records/1188976>.

## Требования

- Python 3.11 или новее;
- [uv](https://docs.astral.sh/uv/).

Создание виртуального окружения `.venv` и установка проекта:

```bash
uv sync
```

`uv sync` автоматически создаёт `.venv`, поэтому отдельно запускать
`python -m venv` и активировать окружение не требуется.

## Создание CSV-разметки

Запуск из корня проекта:

```bash
uv run ravdess-convert
```

Получаемая таблица содержит путь внутри источника, эмоцию, интенсивность,
номер фразы, повтор, номер актёра и пол актёра. В RAVDESS эти поля
закодированы в имени файла вида `03-01-05-02-02-01-12.wav`.

Конвертер предназначен только для речевого аудио. Song и video не
обрабатываются.

Проект использует все восемь классов эмоций из речевой части RAVDESS:

- `neutral` — нейтральное состояние;
- `calm` — спокойствие;
- `happy` — радость;
- `sad` — грусть;
- `angry` — гнев;
- `fearful` — страх;
- `disgust` — отвращение;
- `surprised` — удивление.

В CSV сохраняются все классы. Для полного датасета должно получиться 1440
записей от 24 актёров.

## Извлечение MFCC-признаков

После создания разметки запустите:

```bash
uv run ravdess-features
```

Каждая запись преобразуется в 62 числовых признака: MFCC, delta, delta-delta,
громкость, zero-crossing rate и три спектральные характеристики. Аудио
приводится к частоте дискретизации 16 кГц. Все восемь эмоций сохраняются.

## Проверка

```bash
uv run python -m unittest discover -s tests -v
```

## Обучение моделей

После создания `features.csv` запустите:

```bash
uv run ravdess-classify
```

Скрипт сравнивает Logistic Regression, Random Forest и Gaussian Naive Bayes.
Для Random Forest небольшой набор параметров подбирается через четырёхкратный
GroupKFold по актёрам. Актёры 21–24 используются для будущей посткалибровки,
а 17–20 сохраняются для финального теста и до этого момента не оцениваются.
В `reports/model_metrics.csv` сохраняются только название модели, Accuracy,
Macro F1 и Log Loss.

## Следующий небольшой этап

После подготовки CSV проект можно завершить в минимальном объёме:

1. Обучить один классификатор на подготовленных MFCC-признаках.
2. Получить вероятности восьми классов до калибровки.
3. Применить sigmoid-калибровку.
4. Сравнить Brier score и один график калибровки до и после.

Данные делятся по актёрам: 1–16 для обучения, 21–24 для посткалибровки и
17–20 для финального теста. Записи одного человека не попадают в разные
выборки.
