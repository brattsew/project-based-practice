# Project-Based Practice: польза посткалибровки вероятностей эмоций

Небольшой проект по распознаванию эмоций в речи и последующей
посткалибровке вероятностей моделей. Проект использует речевую часть датасета
RAVDESS и сравнивает три базовых классификатора в четырёх режимах вероятностей:
без калибровки, sigmoid, isotonic и temperature scaling. Итого в финальном
эксперименте сравниваются 12 связок «модель × метод».

## Постановка задачи

Оценить пользу посткалибровки вероятностей классификаторов эмоций в речи:
становятся ли вероятности предсказаний более достоверными после калибровки,
при сохранении самого классификатора и аудиопризнаков без изменений. В качестве
предметной области используется распознавание эмоций в речи.

Польза оценивается на полностью отложенных актёрах по Log Loss, multiclass
Brier Score и ECE. Accuracy и Macro F1 приводятся как контрольные метрики:
калибровка меняет вероятности, но не обязана менять наиболее вероятный класс.

## Что уже реализовано

- чтение речевого ZIP-архива RAVDESS без распаковки;
- создание CSV-разметки из имён аудиофайлов;
- поддержка всех восьми эмоций датасета;
- извлечение 62 аудиопризнаков;
- разделение данных по актёрам;
- обучение Logistic Regression, Random Forest и Gaussian Naive Bayes;
- небольшой подбор параметров Random Forest;
- расчёт Accuracy, Macro F1 и Log Loss;
- сравнение sigmoid, isotonic и temperature scaling на отдельной группе актёров;
- расчёт multiclass Brier Score, ECE, MCE и adaptive ECE;
- разбивка качества калибровки по эмоциям;
- сохранение результатов моделей в CSV;
- сохранение обученных моделей и калибраторов в Joblib;
- простые автоматические тесты.

## Требования

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/brattsew/project-based-practice.git
cd project-based-practice
uv sync
```

Команда `uv sync` автоматически создаст виртуальное окружение `.venv` и
установит проект. Вручную создавать и активировать окружение не требуется.

После установки положите архив RAVDESS в `data/raw/`.

## Полный запуск текущей версии

Все команды выполняются из корня проекта:

```bash
uv run ravdess-convert
uv run ravdess-features
uv run ravdess-classify
uv run ravdess-calibrate
```

### 1. Создание разметки

```bash
uv run ravdess-convert
```

Скрипт читает имена WAV-файлов внутри архива. Например, имя
`03-01-05-02-02-01-12.wav` содержит тип записи, эмоцию, интенсивность, фразу,
повтор и номер актёра.

Результат сохраняется в:

```text
data/processed/ravdess_labels.csv
```

Для полного речевого архива таблица содержит 1440 строк.

### 2. Извлечение признаков

```bash
uv run ravdess-features
```

Все записи приводятся к частоте дискретизации 16 кГц. Для каждой записи
вычисляются 62 признака:

- 13 средних значений MFCC;
- 13 стандартных отклонений MFCC;
- 13 стандартных отклонений delta;
- 13 стандартных отклонений delta-delta;
- среднее и стандартное отклонение громкости RMS;
- среднее и стандартное отклонение zero-crossing rate;
- средние и стандартные отклонения spectral centroid, bandwidth и rolloff.

Delta показывает изменение MFCC во времени, а delta-delta — изменение самой
delta. Они помогают учитывать динамику речи, а не только среднее звучание.

Результат сохраняется в:

```text
data/processed/features.csv
```

### 3. Обучение моделей

```bash
uv run ravdess-classify
```

Обучаются три базовые модели:

- Logistic Regression;
- Random Forest;
- Gaussian Naive Bayes.

В финальном эксперименте каждая из них сравнивается без калибровки и после
трёх методов посткалибровки, поэтому таблица содержит 12 вариантов, а не только
три строки базовых моделей.

Для Random Forest проверяется небольшой набор параметров с помощью
четырёхкратного GroupKFold. Разделение выполняется по актёрам, поэтому записи
одного человека не попадают одновременно в обучение и проверку.

Результат сохраняется в:

```text
reports/model_metrics.csv
```

### 4. Посткалибровка и финальная оценка

```bash
uv run ravdess-calibrate
```

Команда обучает базовые модели только на актёрах 1–16, подбирает sigmoid- и
isotonic-калибраторы на актёрах 21–24, а temperature scaling обучает по NLL на
тех же вероятностях. Затем каждый метод ровно один раз оценивается на актёрах
17–20. Финальные метрики не используют тестовые метки при обучении
калибратора. Результат сохраняется в
`reports/calibration_metrics.csv`, а матрицы ошибок — в
`reports/confusion_matrices.csv`.

## Разделение данных

| Актёры | Назначение                          | Количество записей |
| ------------ | --------------------------------------------- | ----------------------------------: |
| 1–16        | обучение моделей и GroupKFold |                                 960 |
| 21–24       | будущая посткалибровка   |                                 240 |
| 17–20       | финальный тест                   |                                 240 |

Актёры 17–20 пока не использовались для оценки. Финальный тест нужно запустить
только после того, как будет полностью готова посткалибровка.

## Метрики

- **Accuracy** — доля правильно распознанных записей.
- **Macro F1** — среднее значение F1 по всем восьми эмоциям. Каждая эмоция
  имеет одинаковый вес.
- **Log Loss** — оценивает качество вероятностей. Чем меньше значение, тем
  лучше.
- **Brier Score** — средняя квадратичная ошибка между вектором вероятностей и
  one-hot-меткой класса; меньше — лучше.
- **ECE** — Expected Calibration Error по 10 корзинам уверенности; меньше —
  лучше.
- **MCE** — максимальная ошибка среди корзин уверенности; меньше — лучше.
- **Adaptive ECE** — ECE по квантильным корзинам, устойчивее при неравномерном
  распределении уверенности.

Калибровка в первую очередь должна улучшить Log Loss и Brier Score. Accuracy
и Macro F1 могут почти не измениться, потому что наиболее вероятный класс
часто остаётся прежним.

## Текущие результаты

Результаты получены на актёрах 21–24 до посткалибровки:

| Модель         | Accuracy | Macro F1 | Log Loss |
| -------------------- | -------: | -------: | -------: |
| Logistic Regression  |   0.4417 |   0.4353 |   1.9314 |
| Random Forest        |   0.4958 |   0.4772 |   1.5245 |
| Gaussian Naive Bayes |   0.4167 |   0.4139 |   3.5180 |

Сейчас лучший результат показывает Random Forest. Эти значения не являются
финальными результатами проекта, поскольку выборка актёров 21–24 будет
использоваться для обучения калибратора.

## Проверка тестов

```bash
uv run python -m unittest discover -s tests -v
```

Тестам не нужен полный датасет: они проверяют разбор имени файла и наличие
всех восьми эмоций.

## Notebook и ограничения

`notebooks/calibration_analysis.ipynb` загружает итоговые CSV, показывает
таблицу до/после с изменениями, reliability diagram, confusion matrix лучшей
модели и автоматически формирует вывод по Log Loss/Brier/ECE.

Важно учитывать: RAVDESS содержит актёрскую речь и относительно мало данных для
калибровки (240 записей). Разбиение по актёрам снижает утечку, но не устраняет
ограничения внешней обобщаемости; дисбаланс по интенсивности и возможные
путаницы близких эмоций также влияют на результат.

## Возможные улучшения для следующего этапа

Ниже перечислены задачи для дальнейшей командной работы. Они не входят в
текущую реализацию и намеренно оставлены как roadmap.

1. **Расширить модельный baseline.** Добавить SVM с вероятностями и одну
   градиентную модель, сравнивая их с теми же четырьмя режимами калибровки.
2. **Расширить аудиопризнаки.** Проверить 20–40 MFCC, chroma, spectral
   contrast, pitch и признаки пауз/ритма; каждое расширение оценивать отдельным
   абляционным экспериментом.
3. **Добавить аугментацию только на train.** Проверить шум, pitch shift и
   time stretch, не допуская попадания производных одного аудио в calibration
   или test.
4. **Исследовать устойчивость калибровки.** Повторить эксперимент с разными
   размерами calibration set (например, 100 и 240 записей), несколькими seed и
   доверительными интервалами bootstrap.
5. **Сделать статистический анализ по эмоциям.** Проверить, для каких эмоций
   калибровка стабильно улучшает one-vs-rest Brier/ECE, а не только в одном
   разбиении.
6. **Углубить анализ фиксированного датасета.** Исследовать отдельно normal и
   strong intensity, statement/repetition и пол актёра; дополнительно проверить
   устойчивость выводов на нескольких заранее заданных actor-split, не меняя
   состав RAVDESS и не смешивая производные одного аудио между частями.
7. **Усилить воспроизводимость.** Добавить конфигурационный файл, версию
   датасета, checksum архива, журнал экспериментов и CI-проверку notebook и
   CLI на небольшом fixture-наборе.
8. **Подготовить прикладной интерфейс.** Добавить команду инференса для одного
   WAV, которая возвращает класс и calibrated probabilities.
9. **Довести полный расчёт признаков до финала.** Текущий последовательный
   проход по 1440 WAV оказался слишком медленным для практического запуска.
   Следующий шаг — добавить видимый progress/flush, промежуточное сохранение
   чанками и безопасное ускорение обработки (например, параллельно по файлам),
   затем завершить `features.csv` и заполнить реальные отчёты калибровки.
