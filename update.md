# Отчёт об обновлении проекта

## Что было изначально

Проект обучал три базовых классификатора эмоций RAVDESS на 62 аудиопризнаках:
Logistic Regression, Random Forest и Gaussian Naive Bayes. Разбиение по актёрам
уже было задумано правильно, но `ravdess-classify` оценивал модели на группе
21–24 и отдельной посткалибровки не было. В исходном отчёте были только Accuracy,
Macro F1 и Log Loss.

## Что требовалось по README

- добавить `calibrate.py` и команду `ravdess-calibrate`;
- обучать модели на актёрах 1–16;
- использовать 21–24 только для калибровки;
- выполнить финальную оценку только на 17–20 до и после калибровки;
- добавить multiclass Brier Score;
- сохранить `reports/calibration_metrics.csv`;
- подготовить notebook с таблицей, reliability diagram, confusion matrix и выводом.

## Что сделано

1. Добавлен `src/emotion_calibration/calibrate.py` и CLI `ravdess-calibrate`.
2. Добавлены четыре режима сравнения для каждой из трёх базовых моделей:
   без калибровки, sigmoid (Platt), isotonic и temperature scaling. Всего
   сравниваются 12 связок «модель × метод».
3. Реализовано строгое разбиение без пересечения актёров:
   - 1–16 — обучение;
   - 21–24 — обучение калибратора;
   - 17–20 — независимый финальный тест.
4. Добавлены multiclass Brier Score, ECE, MCE и adaptive ECE. Для каждой
   калибровки рассчитывается Δ относительно режима без калибровки.
5. Добавлен отдельный анализ Brier Score по каждой эмоции.
6. Сохраняются модели и калибраторы в `reports/models/`.
7. Добавлены `reports/confusion_matrices.csv` и
   `reports/calibration_by_emotion.csv`.
8. Notebook расширен графиками на русском языке:
   таблица метрик, сравнение методов, reliability diagrams, confusion matrix,
   распределение максимальной уверенности и вывод.
9. Исправлена совместимость с scikit-learn 1.9: вместо удалённого
   `cv="prefit"` используется `FrozenEstimator`, с fallback для старых версий.
10. Добавлены автоматические тесты для метрик, temperature scaling, разбиения
    актёров и наличия всех ключевых полей отчёта.
11. README дополнен постановкой задачи: оценить пользу посткалибровки
    вероятностей распознавания эмоций в речи.

## Новые файлы и отчёты

- `src/emotion_calibration/calibrate.py` — полный pipeline калибровки;
- `tests/test_calibration.py` — тесты новых компонентов;
- `notebooks/calibration_analysis.ipynb` — визуальный анализ;
- `reports/calibration_metrics.csv` — итоговые метрики до/после и Δ;
- `reports/calibration_by_emotion.csv` — анализ по эмоциям;
- `reports/confusion_matrices.csv` — матрицы ошибок;
- `reports/models/` — сохранённые Joblib-артефакты.

Исходный архив `data/raw/Audio_Speech_Actors_01-24.zip` не изменяется.
Производные `ravdess_labels.csv` и `features.csv` создаются из него заново.
